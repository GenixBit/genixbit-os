1. OS Architecture & Design Principles

GenixBit OS is an AI-first, developer-centric Linux distribution designed on top of the Ubuntu 26.04 Resolute LTS foundation. It pairs an optimized local AI inference stack with developer tooling, autonomous agent bridges, and a privacy-preserving desktop environment.

✓ 100% Zero Mandatory Telemetry: All AI inference, model quantization, and agent execution runs strictly on local hardware (CPU, NVIDIA CUDA, AMD ROCm, Intel SYCL, and NPU).

3. Installation Guide

Flash the verified ISO onto a USB flash drive (minimum 8GB) using dd or standard disk writers:

# Linux / macOS (replace /dev/sdX with target USB device) sudo dd if=GenixBitOS-1.0.0-lts-2311142213.iso of=/dev/sdX bs=4M status=progress oflag=sync

4. QEMU / KVM Virtual Machine Testing

Test the ISO in a high-performance virtual machine with KVM hardware acceleration:

# Create a 30GB virtual disk qemu-img create -f qcow2 genixbit-lts.qcow2 30G # Boot ISO in QEMU with 8GB RAM and 4 CPU cores qemu-system-x86_64 \ -enable-kvm -m 8192 -smp 4 \ -cdrom GenixBitOS-1.0.0-lts-2311142213.iso \ -drive file=genixbit-lts.qcow2,format=qcow2 \ -vga virtio -device virtio-net-pci,netdev=net0 \ -netdev user,id=net0,hostfwd=tcp::11434-:11434 \ -boot d

5. Local AI Proxy & System Daemon

GenixBit OS runs an in-process local OpenAI/Ollama-compatible proxy listening on 127.0.0.1:11434:

# Enable and start AI runtime service sudo systemctl enable --now genixbit-ai-proxy # Test health check and hardware detection curl -s http://127.0.0.1:11434/health | jq . # Send OpenAI-compatible streaming completion curl -X POST http://127.0.0.1:11434/v1/chat/completions \ -H "Content-Type: application/json" \ -d '{ "model": "gemma-3-2b-it", "messages": [{"role": "user", "content": "Explain AI-First Linux architecture."}], "stream": true }'

15. ZRAM Dynamic Memory Compaction (`genixbit-zram`)

Prevents Out-Of-Memory (OOM) kills when executing large 7B/14B/32B models by allocating LZ4 compressed swap in RAM:

# Check ZRAM status and compression ratio genixbit-zram status # Enable high-priority LZ4 ZRAM swap pool sudo genixbit-zram enable # Optimize memory compaction parameters genixbit-zram optimize

16. MicroVM Virtualization & Agent Sandboxing (`genixbit-microvm`)

Provisions sub-second (<120ms) hardware-isolated Linux MicroVMs using Firecracker/KVM for running untrusted coding agents and commands:

# Inspect live MicroVM hypervisor instances genixbit-microvm status # Launch hardware-isolated MicroVM with dedicated vCPUs & RAM genixbit-microvm launch --vcpus 2 --mem 2048 # Execute agent command safely within VM boundaries genixbit-microvm exec vm-1723891400 "agy run --goal 'security audit'" # Terminate and scrub ephemeral memory genixbit-microvm destroy vm-1723891400

17. LoRA Adapters & On-Device GGUF Quantization (`genixbit-quant`)

Quantizes FP16 models directly on your hardware and hot-swaps domain fine-tuning LoRA adapters in 42ms:

# View supported quantization formats (Q8_0, Q5_K_M, Q4_K_M, Q2_K) genixbit-quant list # Quantize model to balanced 4-bit format (68% size reduction) genixbit-quant quantize gemma-3-2b-it --type q4_k_m # Hot-swap LoRA fine-tuning weights onto running base model genixbit-quant lora-apply --base gemma-3-2b-it --lora code-lora.safetensors
