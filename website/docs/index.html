1. OS Architecture & Design Principles

GenixBit OS 1.0.0 LTS is an AI-first, developer-centric Linux operating system built on the solid foundation of Ubuntu 26.04 Resolute LTS. It provides 5-year Long Term Support (2026–2031).

The operating system is architected around three foundational pillars:

  • Local-First Artificial Intelligence: Pre-configured, hardware-accelerated OpenAI-compatible API proxy on http://127.0.0.1:11434/v1 with zero telemetry and 100% offline execution.
  • Autonomous Agent Toolchains: Native bridge and diagnostic tooling for Google Antigravity SDK (agy), Gemini CLI, Cursor IDE, OpenAI Codex, and OpenCode.
  • Deterministic Package Governance: 15 modular Debian packages signed cryptographically and built in clean, isolated chroot environments.

3. Installation Guide

Bare-Metal USB Flashing

# Identify your target USB device (e.g. /dev/sdX) lsblk # Flash using direct dd block copy sudo dd if=GenixBitOS-1.0.0-lts-2311142213.iso of=/dev/sdX bs=4M status=progress oflag=sync

Boot the target machine from the USB flash drive and follow the Calamares installation wizard.

4. QEMU / KVM Virtual Machine Testing

Test the ISO in a high-performance virtual machine with KVM hardware acceleration:

# Create a 30GB virtual disk qemu-img create -f qcow2 genixbit-lts.qcow2 30G # Boot ISO in QEMU with 8GB RAM and 4 CPU cores qemu-system-x86_64 \ -enable-kvm -m 8192 -smp 4 \ -cdrom GenixBitOS-1.0.0-lts-2311142213.iso \ -drive file=genixbit-lts.qcow2,format=qcow2 \ -vga virtio -device virtio-net-pci,netdev=net0 \ -netdev user,id=net0,hostfwd=tcp::11434-:11434 \ -boot d

5. Local AI Proxy & System Daemon

GenixBit OS runs an in-process local OpenAI/Ollama-compatible proxy listening on 127.0.0.1:11434:

# Enable and start AI runtime service sudo systemctl enable --now genixbit-ai-proxy # Test health check and hardware detection curl -s http://127.0.0.1:11434/health | jq . # Send OpenAI-compatible streaming completion curl -X POST http://127.0.0.1:11434/v1/chat/completions \ -H "Content-Type: application/json" \ -d '{ "model": "gemma-3-2b-it", "messages": [{"role": "user", "content": "Explain AI-First Linux architecture."}], "stream": true }'

6. Model Pull & Quantization Engine

The genixbit-ai-center CLI manages model downloads, quantization checks, and cache storage:

# 1. View curated models catalog genixbit-ai-center list # 2. Get hardware-aware quantization recommendation genixbit-ai-center quantize-recommend # 3. Pull and register a GGUF model genixbit-ai-center pull gemma-3-2b-it # 4. View locally cached model files genixbit-ai-center models # 5. Run a prompt test genixbit-ai-center run --model gemma-3-2b-it --prompt "List 3 advantages of local AI."

10. Security & Privacy Governance

GenixBit OS guarantees zero mandatory telemetry, offline local AI execution, signed package distribution via GPG keyrings, and strict chroot isolation during build time.

11. Live Web Desktop Simulator & noVNC
