Quick Start Installation Commands

1. Verify ISO Checksum:

sha256sum GenixBitOS-1.0.0-lts-2311142213.iso Expected: 229b3f70f94d0ced...

2. Create Bootable USB Media (replace /dev/sdX carefully):

sudo dd if=GenixBitOS-1.0.0-lts-2311142213.iso of=/dev/sdX bs=4M status=progress conv=fdatasync

3. Test under QEMU / KVM Virtual Machine:

qemu-system-x86_64 -m 4096 -smp 2 -enable-kvm -cdrom GenixBitOS-1.0.0-lts-2311142213.iso
