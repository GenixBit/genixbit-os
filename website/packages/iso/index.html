Verification Instructions

Verify the integrity of downloaded installation media before flashing to USB storage or loading into a hypervisor:

# Linux / macOS checksum verification:
curl -sL https://packages.os.genixbit.com/iso/SHA256SUMS | sha256sum -c --ignore-missing

# Or direct file check:
sha256sum GenixBitOS-1.5.0-sutra-20260817.iso
