## 2. Milestone Feature Tracks

### Track 1: Bharat AI (IndicLLM) Multilingual Subsystem
- **22 Scheduled Indian Languages**: Native support for Hindi (hi), Tamil (ta), Telugu (te), Bengali (bn), Marathi (mr), Gujarati (gu), Kannada (kn), Malayalam (ml), Odia (or), Punjabi (pa), Urdu (ur), Assamese (as), and more.
- **Transliteration & Typing**: System-wide input method and transliteration engine (`genixbit-ai-center bharat-transliterate`).
- **Offline Speech-to-Text (`genixbit-voice`)**: Voice transcription for terminal commands and coding agent prompting.

### Track 2: Native Graphical UI Application Suite
- **GenixBit Store GUI (`genixbit-store-gui`)**: Graphical package, Flatpak, and GGUF model manager with verified developer badges.
- **Agent Studio GUI (`genixbit-agent-studio`)**: Visual multi-agent workflow builder for Google Antigravity SDK, Gemini CLI, Cursor, and Codex.
- **System Monitor GUI (`genixbit-monitor-gui`)**: Real-time animated charts for CPU, RAM, GPU, VRAM, and AI inference latency.

### Track 3: NPU Acceleration & Low-Latency Kernel Tuning
- **Neural Processing Unit (NPU)**: Auto-detection for Intel Core Ultra NPU (`/dev/accel/`), AMD Ryzen AI XDNA, and ARM SoC accelerators.
- **Kernel Tuning Profile**:
  - `vm.max_map_count = 1048576` (enables large LLM context memory mapping).
  - `vm.swappiness = 10` (prevents swapping model weights).
  - `memlock unlimited` (pins inference memory).

### Track 4: LAN Model Mesh (`genixbit-mesh`)
- **Distributed Inference**: Multi-node LAN model serving allowing low-power laptops to offload inference to a local GenixBit workstation.
- **Zero-Trust Remote Tunnel (`genixbit-tunnel`)**: Secure encrypted developer access.
