# GenixBit OS 1.0.0 LTS Stable Release Specification

> **Official Release Architecture & Production Governance Specification**

## Overview

**GenixBit OS 1.0.0 LTS** is the production-ready, AI-first, local-first Linux operating system built on Ubuntu 26.04 Resolute base by **GenixBit Labs Private Limited**.

---

## 1. System Specifications & LTS Support

| Specification | Target Value |
| --- | --- |
| Operating System Name | **GenixBit OS 1.0.0 LTS** |
| Base Distribution | Ubuntu Linux 26.04 Resolute LTS |
| Target Architecture | `amd64` (x86_64) |
| Desktop Environment | GNOME 50 (Customized GenixBit Theme & Workspace) |
| Release Status | **Production Certified (100% Release Gate PASS)** |
| Support Lifecycle | **5-Year Long-Term Support (LTS) (2026 - 2031)** |
| License | GPL-3.0 for covered source |

## 2. Complete Native Package Ecosystem (15 Packages)

| Package Name | Category | Function & Scope |
| --- | --- | --- |
| `genixbit-os-base-files` | Core System | System release identity (`/etc/os-release`, `/etc/issue`) |
| `genixbit-os-desktop` | Metapackage | Core GNOME desktop environment & AI workspace defaults |
| `genixbit-os-theme` | Artwork | Plymouth boot splash & GNOME desktop artwork styles |
| `genixbit-os-wallpapers` | Artwork | High-resolution workstation background wallpapers |
| `genixbit-os-installer-config` | Installer | Custom Calamares / Ubiquity slides & autoinstall profiles |
| `genixbit-os-archive-keyring` | Security | Public OpenPGP GPG signing key keyring package |
| `genixbit-os-apt-config` | Repository | APT repository channel configuration (`resolute-alpha`, `testing`, `stable`) |
| `genixbit-os-developer-profile` | Profile | Git, Docker, Python, Node.js, Go, Rust, Java toolchains |
| `genixbit-os-server-profile` | Profile | Headless server services, systemd monitoring, firewall & remote admin |
| `genixbit-os-creator-profile` | Profile | Video, audio, image, 3D graphics, streaming & hardware codecs |
| `genixbit-os-gpu-diagnostics` | Utility | NVIDIA / AMD / Intel GPU detection (`genixbit-gpu-diag`) |
| `genixbit-os-ai-runtime` | AI Engine | Local OpenAI API proxy on port 11434 (`genixbit-ai-proxy`) & model catalog |
| `genixbit-os-ai-center` | AI Manager | CLI model lifecycle & parameter manager (`genixbit-ai-center`) |
