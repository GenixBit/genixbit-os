# GenixBit OS — Networking, Bluetooth & VPN (GenixNetwork)

## 1. Network Subsystem
GenixNetwork provides fast, secure connectivity supporting IPv4/IPv6, Wi-Fi 6E/7, Bluetooth 5.4, WireGuard VPN, and network namespace isolation.

---

## 2. Key Components
- **Wi-Fi & Ethernet Manager**: NetworkManager with iwd backend for fast roaming.
- **WireGuard VPN**: Native kernel-level mesh VPN integration with instant kill-switch.
- **Bluetooth Stack (BlueZ 5.75)**: High-resolution LDAC and AAC audio streaming, low-energy HID peripherals.
- **Network Security**: Per-application firewall filtering and zero-trust port access.
