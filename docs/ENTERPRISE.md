# GenixBit OS — Enterprise Management & System Profiles (GenixEnterprise)

## 1. Workstation Profiles
GenixBit OS offers pre-configured, optimized profiles for distinct enterprise and creative workloads:

- **Developer Profile (`genixbit-os-developer-profile`)**: Pinned compilers and toolchains for Python, Rust, Go, Node.js, C/C++, Docker, and microVM drivers.
- **Creator Profile (`genixbit-os-creator-profile`)**: High-performance audio/video codecs, OBS streaming, PipeWire pro-audio routing, and Blender 3D acceleration.
- **Server Profile (`genixbit-os-server-profile`)**: Headless administration, automated security updates, systemd service supervision, and WireGuard mesh networking.
