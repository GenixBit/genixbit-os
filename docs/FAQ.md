# GenixBit OS — Frequently Asked Questions (FAQ)

### 1. What makes GenixBit OS different from standard Linux distributions?
GenixBit OS is built as an integrated, AI-native platform with:
- Native local LLM and multi-agent swarm runtimes on `127.0.0.1:11434`.
- Privileged AI capability security model with real-time audit logging.
- Native `.gbx` self-contained package manager with atomic rollbacks.
- GenixKit Developer SDK for application lifecycle and local AI inference.
- Refined macOS-style workstation UI with traffic light window controls and floating glass dock.

---

### 2. Can I run existing Linux and Debian applications?
Yes. GenixBit OS provides full binary compatibility with standard Debian/Ubuntu `.deb` packages, Flatpak, OCI containers, and native `.gbx` application bundles.

---

### 3. How does GenixBit OS handle privacy and AI security?
All AI models run 100% locally by default on your hardware. High-risk operations (modifying system configuration, accessing private documents, network access) require explicit user consent and are recorded in an append-only audit trail.
