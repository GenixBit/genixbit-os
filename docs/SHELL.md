# GenixBit OS — Desktop Shell (GenixShell)

## 1. Desktop Shell Architecture
GenixShell provides a unified, glassmorphic workstation experience:

- **macOS-Style Top Menu Bar**:
  - Left: `[ G ]` System Menu, Bold App Identifier, Global App Menus (`App`, `File`, `Edit`, `View`, `AI`, `Window`, `Help`).
  - Right: `☁️` Cloud Sync, `✨` AI Assistant, `🛡️` Guard, `🌙` Focus Moon, `🔋` Battery, `📶` Wi-Fi, `🔍` Spotlight Search, `🎛️` Control Center, Clock.
- **Traffic Light Window Controls**: Left-aligned circular controls (🔴 Close, 🟡 Minimize, 🟢 Zoom/Maximize).
- **Floating Dock (`GenixBit-Glass`)**: Centered 24px rounded frosted glass capsule with active glow indicators.
- **Quick Launcher (`genixbit-launcher`)**: Fast fuzzy application and file search triggered via `Super+Space`.
